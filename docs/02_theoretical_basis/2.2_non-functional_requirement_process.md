**2.2 Process Description of Non-Functional Requirements**

**2.2.1 Performance & Response Time:**
- Barcode scan processing time for circulation <= 1.5 seconds per transaction.
- Online catalog search (OPAC) response time <= 2 seconds for a database containing up to 100,000 titles.

**2.2.2 Security & Authorization:**
- Encrypt user passwords and sensitive personal data.
- Automatic session timeout for librarian accounts after 15 minutes of inactivity to prevent unauthorized access.
- Strict authorization requiring elevated authentication for critical data modifications (deleting books, waiving fines, exporting reports).

**2.2.3 Reliability & Availability:**
- System uptime >= 99.5%, particularly during library operating hours.
- Automatic daily database backups.

**2.2.4 Scalability & Usability:**
- User-friendly interface responsive across desktop (Librarians) and mobile devices (Readers).
- Ready to integrate with e-payment gateways (Momo, VNPay) for online fine payments and automated access control gates.

**2.2.5 Legal Compliance:**
- Issue electronic invoices in compliance with Decree 123/2020/ND-CP; calculate VAT tax reports automatically.
- Retain financial data for at least 10 years according to Accounting Law; protect personal data under Decree 13/2023/ND-CP.

**2.2.6 Cost Efficiency:**
- Cloud infrastructure operating costs automatically scale based on load (auto-scaling).
- Lower dev/staging environment expenses by at least 60% compared to production.
- Establish replacement plans with open-source alternatives if third-party software licensing costs exceed thresholds.
