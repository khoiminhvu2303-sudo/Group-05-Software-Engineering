**2.6 Data standardization**

Definition: Normalization is the process of decomposing (splitting) a table into smaller tables based on functional dependencies. Normal forms serve as guidelines for designing database tables.

Purpose: To eliminate data redundancy and prevent anomalies during data manipulation operations (Insert, Delete, Update).

Normal Forms (NF):

+First Normal Form (1NF): Each cell must contain a single (atomic) value, each column must hold the same data type, and each row must be uniquely identifiable (by defining a primary key).

+Second Normal Form (2NF): Must satisfy 1NF, and all non-key columns must fully depend on the primary key. That is, no non-key column can partially depend on any part of a composite primary key.

+Third Normal Form (3NF): Must satisfy 2NF and contain no transitive dependencies (when a column depends on another non-key column, not directly on the primary key).
