# Explanation of the list of abbreviations

**Group 1: Library Management Terminology**

- LMS (Library Management System): Core software application used to manage library operational workflows.

- ISBN (International Standard Book Number): Unique commercial numeric identifier assigned to each book edition.

- OPAC (Online Public Access Catalog): Online database of materials held by the library accessible to users.

**Group 2: Database Management & Modeling**

- DBMS (Database Management System): Software system used to store, manage, and retrieve database data.

- RDBMS (Relational Database Management System): Software system used to manage data stored in structured tables using rows, columns, and relational keys.

- SQL (Structured Query Language): Standardized programming language used to manage relational databases.

- DB (Database): An organized collection of structured data stored electronically.

- ERD (Entity-Relationship Diagram): Diagram depicting database entities and their structural relationships.

- PK (Primary Key): A unique column constraint identifying each record in a database table.

- FK (Foreign Key): A field referencing the Primary Key of another table to link records.

- 1NF, 2NF, 3NF (Normal Forms): Progressive database normalization standards applied to eliminate data redundancy, ensure integrity, and prevent anomalies.

**Group 3: Software Engineering & Technology**

- UI/UX (User Interface / User Experience): Visual design layout and end-user interactive experience of the software.

- API (Application Programming Interface): Set of rules enabling data communication between frontend and backend.

- SRS (Software Requirements Specification): Comprehensive document detailing system features and operational rules.

- DFD (Data Flow Diagram): Graphical representation illustrating how data flows through the system.

- QR Code (Quick Response Code): A two-dimensional matrix barcode scanned to quickly identify and process library physical assets, book copies, or patron cards.

- MVC (Model - View – Controller): A software architectural pattern that separates application logic into three main components: data management (Model), user interface (View), and input control (Controller).

- (Graphical User Interface): Visual interface allowing users to interact with the system through graphical elements like buttons, menus, and forms.

- HTML (Hyper Text Markup Language): Standard markup language used to create and structure web pages and user interfaces for web applications.
