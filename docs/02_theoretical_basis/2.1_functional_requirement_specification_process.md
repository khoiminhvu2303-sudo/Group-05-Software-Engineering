**2.1 Process Description of Functional Requirements**

**2.1.1 Reader Management:**
- Register, update information, and renew library cards.
- Categorize readers (Students, Faculty, External Guests) to apply corresponding borrowing policies.
- Lock/unlock reader accounts upon policy violations (e.g., overdue items, unpaid fines).

**2.1.2 Catalog & Inventory Management:**
- Manage book metadata (ID book, title, author, publisher, publication year, category).
- Manage individual physical copies (ID copy, shelf location, status: available, borrowed, damaged, lost).
- Perform inventory audits, add new stock, or liquidate damaged/outdated books.

**2.1.3 Borrowing & Returning Management:**
- Create borrowing receipts (checking card validity and borrow limits).
- Process book returns and handle borrow extensions.
- Automatically calculate fines for overdue, damaged, or lost books.

**2.1.4 Staff & Role Management:**
- Manage staff/librarian profiles, work shifts, and assigned departments.
- Implement Role-Based Access Control (RBAC): Admin (Full privileges), Circulation Librarian (Issue/return borrows, collection of fines), Cataloging Librarian (Manage book inventory/titles).
- System Audit Log: Track detailed staff activity logs for accountability.

**2.1.5 OPAC & Book Reservation:**
- Multi-criteria search functionality (title, author, category, keywords) for readers.
- Enable book reservation for items currently out of stock.

**2.1.6 Reporting & Analytics:**
- Generate statistics on borrow frequencies and top-borrowed books.
- Report overdue readers and aggregate revenue from fines and card fees.
