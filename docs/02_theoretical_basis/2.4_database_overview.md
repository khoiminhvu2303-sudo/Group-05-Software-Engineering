# 2.4 Overview CSDL
**2.4.1 Concept of the management process**
Catalogue Management

•	Books: Store information for each book (Book ID, Title, Summary, Publication Year, Stock Quantity, Status).

•	Authors: Manage author information (Author ID, Author Name, Biography).

•	Categories: Classify books for easy lookup (Category code, Category name).

•	Publishers: Information regarding the printing and publishing entity.

Reader Management

•	Reader: Store borrower information (Reader ID, Full name, Date of birth, Address, Email, Library card expiration date).

Circulation Management

•	Borrow_Records: Record the overview information for each transaction (transaction ID, Reader ID, loan date, expected return date, and staff ID).

•	Borrow_Details: Decompose the LoanRecord table to manage multiple books within a single loan transaction (Loan Slip ID, Book ID, book status at time of borrowing/return, actual return date, and fines for overdue returns or damage).

Staff Management

•	Staff: Manage information on librarians or internal system users (Employee ID, Name, Position, Login account, Admin).
