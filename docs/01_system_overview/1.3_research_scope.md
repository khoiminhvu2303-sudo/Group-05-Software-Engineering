**1.4 Research Scope
*1.4.1 Functional Scope
Account Management: Manage user information and user roles/permissions (Staff, Admin, Reader)
Borrowing and Return Management: Track borrowing/return schedules, record borrowing transactions, and update document status (damaged, overdue)
Library Management: Manage categories, book information, and publishers
Fine Management: Calculate overdue borrowing/return fees, record damaged book charges, and generate invoices
Reports and Statistics: Overdue document lists and rankings of most borrowed books
*1.4.2 System Limitations
Automated Email/SMS notifications are not yet integrated
Online payment systems are not yet integrated
