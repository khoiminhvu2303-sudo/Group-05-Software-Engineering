# 1.2 System Objectives

In the context of the increasing demand for learning, research, and reading culture, educational libraries and resource centers are expanding rapidly with a large volume of readers and diverse document categories. Managing information regarding readers, book collections, borrowing/returning transactions, and overdue fines using manual methods or disjointed tools often leads to errors, data loss, and operational inefficiencies.

To address these challenges, the project "Library Management System " is implemented to build a centralized management platform that efficiently and accurately supports and automates library operations.

* Reader (member) management.
* Book and document catalog management.
* Staff/librarian management.
* Book borrowing and return process management (analogous to managing training schedules or packages).
* Payment management (card issuance fees, late fees).
* Automated statistics and reporting.
