2. User groups
   
Class Name: Reader

-	Class Attributes (Private - ):
  
•	– ReaderID: string (PK)

•	– FullName: string (full name)

•	– DOB: date (date of birth)

•	– Phone: string

•	– Email: string

•	– Address: string

•	– CCCD: Input

•	– StartDate: date (Library card creation date)

•	– ExpiryDate: date (Card expiration date)

•	– Username: string

•	– Password: string

-	Methods (Public +):
  
•	+ login (user, pass): boolean

•	+ searchBook(keyword): List<Book>

•	+ reserveBook(bookID): boolean (reserve book online)

•	+ renewBookOnline(bookID): boolean (renew book online)

•	+ viewBorrowHistory(): List<BorrowRecord>

Class Name: Staff

-	Attributes (Private -):
  
•	– staffID: string (PK)

•	– Name_Staff: string

•	– gender: string

•	– DOB_Staff: Date

•	– Numberphone_Staff: string

•	– email: string

•	– address: string

•	– CCCD: Input

•	– salary: double (Librarian salary)

•	–  NameLogin_Staff: string (Counter management system login name)

•	–  Password_Staff: string

•	–  managedByAdminID: string (FK - ID of the direct supervising Admin)

-	Methods (Public +):
-	
•	+ login(user, pass): boolean

•	+ manageBook(bookDetails): void (Add/Edit/Delete books and categories)

•	+ processBorrow(readerID, listBookID): BorrowRecord (Create book borrowing record)

•	+ processReturn(transactionID): void (Process returned books)

•	+ createFineReceipt(transactionID, reason, amount): FineReceipt (Create fine receipt)

•	+ processFinePayment(fineID): boolean (Confirm fine payment & issue receipt)

Class Name: Admin

-	Attributes (Private -):
  
•	–  AdminID: string (PK)

•	–  AdminName: string

•	–  Email: string

•	–  Phone: string

•	–  CCCD: input

•	– Salary: double

•	–  NameLogin_Admin: string (High-level admin account)

•	–  Password_Admin: string

-	Methods (Public +):
  
•	+ login(user, pass): boolean

•	+ manageStaffAccount(staffID, action): void (Grant/Lock librarian account)

•	+ approveReaderCard(readerID): void (Approve reader card registration from the Web)

•	+ generateSystemReport(type): Report (Compile statistics & generate fine revenue reports)

3.	Circulation & Fine Subsystem
   
Class Name: BorrowRecord

-	Attributes (Private -):
  
•	– transactionID: string (PK)

•	– readerID: string (FK - Links to the borrower)

•	– staffID: string (FK - Links to the librarian who created the record)

•	– DateBorrow: Date (Borrowing date)

•	– DueDate: Date (Scheduled return date)

-	Methods (Public +):
  
•	+ calculateOverdueDays(): int (Calculates the actual number of overdue days)

Class Name: BorrowDetail

-	Attributes (Private -):
  
•	– BorrowDetail_ID: string (PK)

•	– transactionID: string (FK - Associated borrow record)

•	– bookID: string (FK - Specific book)

•	– bookStatus: string (Book condition upon return: Intact, damaged, etc.)

•	– Describe: string (Detailed description of book status, on-time/early return)

•	– actualReturnDate: Date (Actual date the book was returned)

•	– DateIssued: Date (Date the system or librarian created the detail record)

Class Name: FineReceipt

-	Attributes (Private -):
  
•	– fineID: string (PK)

•	– transactionID: string (FK - References the borrow record causing the violation)

•	– Describe: string (Reason for fine: Late return, damaged book, etc.)

•	– amount: double (Fine amount to be collected)

•	– paymentStatus: string (Status: Pending payment / Paid)

-	Methods (Public +):
  
•	+ updatePaymentStatus(status): void (Updates status when the librarian records payment collection)

Class Name: FineReceiptDetail

-	Attributes (Private -):
  
•	– FineReceiptDetail: string (PK)

•	– FineID: string (FK - References the FineReceipt table to link to the fine record)

•	– ReaderID: string (FK - References the Reader table to identify the reader)

•	– FineReceiptStatus: string (Processing status of the specific fine record)

•	–  DateBorrow: date (Date the reader borrowed the book involved in the violation)

•	–  DueDate: date (Date the reader returned the book involved in the violation)

•	–  Describe: string (Detailed description of the violation)

•	–  DateIssued: date (Date the system or librarian created the fine record)

•	–  Amount: double (Fine amount incurred specifically for the book involved in the violation)

Relationships

-	Admin – Staff: 1 – 1..* (via FK managedByAdminID)
  
-	Reader – BorrowRecord: 1 – 0..* (Label: Borrows)
  
-	Staff – BorrowRecord: 1 – 0..* (Label: Creates record)
  
-	Composition: BorrowRecord – BorrowDetail: 1 – 1..* (Label: Consists of)
  
-	BorrowRecord – FineReceipt: 1 – 0..1 (Label: Generates)
  
-	BorrowDetail – Book: 1..* – 1 (Label: Borrowed item) (Shared)
  
-	Book – Category: 0..* – 1 (Label: Belongs to)
  
-	Book – Author: 0..* – 1 (Label: Written by)
  
-	Book – Publisher: 0..* – 1 (Label: Published by)
  
-	FineReceipt – FineReceiptDetail: 1 – 1..* Composition (Label: Violation details)
  
-	Staff – Book: 1..* – 1..* (Label: Manages books) Dependency (dashed line)
