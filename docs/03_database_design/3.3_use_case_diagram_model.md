# Actors:
**Establish a common Actor structure:**

Admin, Staff, and Reader utilize generalization, sharing common features such as logging in, logging out, changing passwords, and viewing personal information. The hierarchy is Admin -> Staff -> Reader. Guests, on the other hand, are limited to searching for books and registering an account.

**Use-case grouping:**

**1: Search and Reader functions (Guest and Reader):**

-	Guest:
  
o	Search for books (with filtering or exclusion options)

o	Register for a reader account

-	Reader:
  
o	Reserve books and add them to an online list

o	Renew books online

o	View borrowing/return history

**2: Staff functions (Librarian):**

-	Staff (Librarian): Handles counter-based operations:
  
-	Staff (Inherits from Reader):
  
o	Manage book catalog (Add/edit information on books, authors, and publishers)

o	Process book borrowing/returns

o	Process renewals at the counter

o	Issue fine slips and collect payments

**3: For Admin:**

-	Admin (Inherits from Staff):
  
o	Manage Staff (account creation, permission assignment, and account locking)

o	Manage Readers: Approve card issuance and manage reader card lifecycles

o	Statistics and reporting

**Relationships:**

**<<extend>> relationship for book return processing:**

-	Base use case: Process book return
  
-	Extension/target use case: Issue a fine slip
  
-	A fine slip is generated only when a reader violates the rules.
  
**<<extend>> relationship for lookup:**

-	Base use case: Search for books
  
-	Target use case: Place a hold on a book
  
-	A reader chooses to place a hold only after finding the desired book.
  
**<<include>> relationship for security:**

-	Base use cases: Statistics and reporting (Admin) and Process borrowing/returning (Staff)
  
-	Included/target use case: Log in
  
-	Login is mandatory to perform these operations.
  
# Summary of functions (to clarify the above):

**Guest:**

-	Search for books
  
-	Register for a reader account
  
-	Log in
  
**User:**

-	Log in
  
-	Log out
  
-	View personal information
  
-	Change password
  
**Reader:**

-	Renew borrow online
  
-	Place book holds online
  
-	View borrowing/return history and personal fines

**Staff:**

-	Process book borrows
  
-	Handle book returns
  
-	Issue fine slips and collect payments
  
-	Manage book catalog
  
**Admin:**

-	Manage Staff accounts
  
-	Manage Reader accounts (Approval and lifecycle management)
  
-	Statistics and financial reporting
  
**<<include>> relationships:**

-	View/update information <<include>> Login (requires login)
  
-	Change password <<include>> Login (requires login)
  
-	Renew books directly <<include>> View personal borrowing/return and fine history (Reader)
  
-	Process book borrowing <<include>> Authenticate reader card (Staff)
  
-	Approve reader card issuance <<include>> View account registration list (Admin)
  
**<extend> relationships:**

-	Recover password <<extend>> Login (requires login)
  
-	Place book on hold <<extend>> Search for materials (Reader)
  
-	Handle violations and issue fine slips <<extend>> Process book returns (Staff)
  
-	Collect fines <<extend>> Handle violations and issue fine slips (note the arrow direction) (Staff)
